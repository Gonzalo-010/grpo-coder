Conectando…

Tarea

El modelo escribe la función, el sandbox la prueba y cada fallo vuelve al modelo con su error, hasta que pasa todos los tests o se acaban las rondas.


    

    

      
      
      
      
    

    

    

  


  

    
Agente

    
Trabaja sobre una copia del proyecto: edita, ejecuta los tests en el sandbox y corrige con su salida.
      Tu proyecto sólo cambia si aplicas el diff.

    
    
    

      

      

      

    

    

    

  


  

    
Entrenamiento

    
Se ejecuta como un proceso aparte. Detenerlo guarda un checkpoint del último step completo;
      volver a iniciarlo continúa desde ahí, salvo que marques un run nuevo.

    

      

        

      

    

    

      
      
    

    

    

    
Salida del proceso

    
Sin entrenamiento lanzado desde el panel.

  


  

    
Checkpoints

    
Runs guardados en runs/. «Usar» carga ese checkpoint para las tareas y el agente;
      «Ver métricas» muestra sus curvas en Entrenamiento.

    

  


  

    
Ajustes

    
Se guardan aparte (runs/ui) y se aplican a lo que lances desde el panel; config.yaml no se toca.
      Los marcados cambian el estado del modelo: el siguiente entrenamiento empezará un run nuevo.
